# ADR-0007: 衝突偵測採「圖遍歷 → FTS5 檢索 → LLM 判斷」三層

## 狀態(Status)

accepted

## 背景(Context)

「新劇情會不會和過去的故事衝突」是 story-flow 存在的理由,也是 design-studio 完全做不到的事
(它的粒度是整份文件,而衝突發生在文件內部的某一段)。

直覺的作法是把整個世界觀丟給 LLM 問「有沒有矛盾」。這在片段只有幾十個時可行,幾百個之後
就撞牆:context 塞不下、成本線性上升、而且 LLM 在大量無關文字裡找矛盾的召回率很差。反過來,
純程式的作法(只看關聯圖)只能找到**已經被標註過**的矛盾——但作者要是知道有矛盾,早就標了。

## 決策(Decision)

分三層,每層職責不同、成本遞增、輸出遞減:

**第 1 層 — 圖遍歷(確定性、零成本)**

順著草稿已引用片段的 `contradicts` / `supersedes` 關聯遍歷,找出已知矛盾與已被取代的設定。
這一層完全可重現、不需要任何模型,回答的是「你正在引用一個已經被推翻的設定」。

**第 2 層 — FTS5 檢索(撈候選)**

以草稿的關鍵詞加上比對到的 `aliases`,用 FTS5 trigram 撈出 top-N 候選片段。過濾條件:

- 只取 `status = canon`——草稿不是「過去的故事」,拿它比對只會製造假衝突(ADR-0003)
- 用 `timeline` 過濾時序上不可能相關的片段
- 用關聯圖擴充一跳範圍(候選的 `partOf` / `occursIn` 目標一併帶進來)

**第 3 層 — LLM 判斷(語意)**

把候選逐對(草稿 × 候選片段)送給 LLM 問「這兩段是否矛盾、矛盾在哪」。優先送 `summary` 而非
全文,必要時才展開 `body`——這是控制 token 成本的主要手段。

輸出的 conflict report 每一筆都帶 **(候選片段 id, 命中層級, 理由)**。命中層級必須標示出來:
第 1 層的結果是事實,第 3 層的結果是判斷,使用者需要知道差別。

另外提供 `story-flow context --for <草稿>` ——**只跑前兩層**,把相關片段撈出來就交還。這條路
給外部 AI Agent 用:claude code 自己有很強的判斷能力,它常常只需要精準的 context,不需要
story-flow 代它判斷。

## 考慮過的替代方案(Alternatives Considered)

- **只做檢索,判斷完全交給外部 Agent**:核心零 LLM 相依、完全可測試,是很乾淨的設計。
  但這樣地端 LLM 的路徑就沒有衝突偵測能力,而「不依賴外部服務也能用」是本專案明確的需求。
  折衷是把它保留為 `context` 指令(前兩層),而非唯一選項。
- **三層再加向量 embedding 語意檢索(sqlite-vec)**:第 2 層的召回率會明顯提升,尤其是換句話說
  的同義描述。但要多一個 embedding 模型相依、多一套索引要跟著檔案更新、且 embedding 模型換掉
  時整個索引要重算。決定先不做——但第 2 層的介面刻意設計成「候選撈取策略」可替換,未來要加
  只是多一個策略並在排序時合併。
- **把整個世界觀丟給 LLM**:實作最簡單,片段少時效果也不差。但成本與召回率都隨規模惡化,
  而規模成長正是這個工具的使用前提。

## 影響(Consequences)

**正面**

- 大部分查詢在前兩層就結束,只有真正需要語意判斷的少數對才燒 token
- 前兩層完全確定性,可以寫測試、可以重現、可以在沒有任何模型的環境跑
- `context` 指令讓外部 Agent 拿到精準 context 而不被 story-flow 的判斷綁住
- 三層各自可獨立演進:結構層加推論規則、檢索層換策略、判斷層換 prompt/模型,互不牽動

**負面 / 成本**

- 召回率受限於 FTS5 的詞彙比對。換句話說的同義描述(「她父母死於徵召」vs「雙親在那場徵召中
  沒能回來」)可能撈不到。緩解:`aliases` 欄位、`summary` 一併進索引、關聯圖擴充一跳;
  仍不夠時才考慮引入 embedding
- 第 3 層的品質完全取決於模型。地端小模型可能誤判,因此輸出必須標示命中層級,並且
  **永不自動修改資料**——衝突報告只是報告,是否成立由作者判斷
- 成本與延遲會隨候選數量上升。top-N 的 N 要可調,且預設保守

**中立**

- 第 1 層的價值取決於作者/AI 是否勤於標註 `contradicts` / `supersedes`。CLI 與 API 在確認
  衝突後應主動提示「要不要建立這條關聯」,讓下次變成零成本的確定性命中
